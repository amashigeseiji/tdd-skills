# 対話規範

このスキルのすべての「提示 → 承認」に適用される。該当する局面は、語彙登録（[語彙規範](./vocabulary.md)
の表＋承認）、ツリー確認、パターン照合での再構成案の比較である。

---

## 提示はターンの最後のテキストであること

**表と確認ダイアログを同じターンに置かない。** ダイアログツール（AskUserQuestion 等）の直前に出した
テキスト出力は、ダイアログの UI の背後に埋もれてユーザーに届かないことがある — そのとき承認は
名前だけの選択に退化する。

**この承認にダイアログツールを使わない。** 表と確認したい点をプレーンテキストとして置いてターンを
終え、ユーザーのテキスト返答から承認を取る。

**ユーザーが見なければならないものは、そのターンの最後のテキストでなければならない。そのあとに
ツール呼び出しを置かない。**

## 承認の対象を名前の列挙に退化させない

承認を求めるとき、ユーザーが判断すべき内容そのものを提示する。名前だけを並べたり、名前を選択肢に
した形で承認を求めない。何が承認されたのかは、提示された内容の範囲までしか及ばない。

## 工程スキップを含意する曖昧な指示は聞き直す

「リファクタリングをやってほしい」のように、現在の工程の残りを飛ばすとも読める指示を受けたとき、スキップの意図かどうかを推定で埋めず、聞き直す。
承認の拍（ツリー確認・語彙登録）を飛ばす解釈を暗黙に採らない。

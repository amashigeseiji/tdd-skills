1. **lint の実装** — `@vocab` / `describe()` / 実装名 / `src` の対応検査の機械化。
   完成したら compose「5. 突合（暫定）」を削除する。
2. **solution ドメインの `src` を書く箇所がない** — 旧ステップ9の「語彙 → src」が全ドメインの
   `src` を書いていた。`ui` は compose「意匠の完成」手順1 に救済したが、solution は縮約版の
   対応表の目視に依存している。lint 化で解消される想定。
3. **design-token を登録する契機がスキル体系のどこにもない** — 現在の登録点は
   `/tdd-vocab init` の初期抽出のみで、tdd-run は適用しかしない。実装中に「この役割の
   トークンがまだない」と気づいたときの経路がない（今回の分割以前からの穴）。
4. **実装中に語彙を発見したときの契機が compose から消えた** — 命名機会の三箇条（削除項目2）が
   その契機だった。残る登録経路は材料化の solution 語彙・型抽出時の `@vocab`・意匠の命名のみ。
5. **rationale.md の改訂**（移植指示 §5）— 見送り。Test and module design 節の移設と、
   Jackson machine / Norman signifier への但し書き追記の2件が未着手。
6. **tdd-run/skill.json の description が古い** — 「design.md の受け入れ条件を検証する」とあるが
   design.md は現存しない。今回のスコープ外として未変更。
7. **複数エントリーポイント／複数ツリー機構** — 再設計ノート §9 のとおり将来検討。
   受け皿は decompose の部分木再入口。
